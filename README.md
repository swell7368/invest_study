# 반도체 섹터 가치투자자 되기

목표: 반도체 산업을 깊이 이해하고, 가치투자 원칙에 따라 개별 기업을 분석·평가할 수 있는 역량을 기른다.

## 폴더 구조

| 폴더 | 내용 |
|---|---|
| [01_가치투자_기초](01_가치투자_기초/) | 안전마진, 내재가치, 경제적 해자 등 핵심 개념 정리 |
| [02_반도체_산업_이해](02_반도체_산업_이해/) | 밸류체인, 사이클, 용어집 등 산업 배경지식 |
| [03_기업분석](03_기업분석/) | 개별 기업 분석 (템플릿 사용, 기업당 폴더 1개) |
| [04_밸류에이션](04_밸류에이션/) | 밸류에이션 방법론과 반도체 특유의 주의점 |
| [05_감시목록](05_감시목록/) | 관심 종목 트래킹 시트 (watchlist.csv) |
| [06_독서노트](06_독서노트/) | 추천도서 목록 + 책별 독서노트 |
| [07_투자일지](07_투자일지/) | 실제 매수/매도 의사결정 기록 (사후검토용) |

## 사용법

1. `02_반도체_산업_이해`부터 읽고 산업 배경지식을 쌓는다.
2. `01_가치투자_기초`로 평가 프레임워크를 익힌다.
3. 관심 기업이 생기면 `03_기업분석/_템플릿.md`를 복사해 `03_기업분석/<기업명>.md`로 분석을 채운다.
4. 분석이 끝난 기업 중 계속 지켜볼 것은 `05_감시목록/watchlist.csv`에 등록한다.
5. 실제로 매매를 하면 `07_투자일지`에 근거와 가정을 남긴다 — 나중에 맞았는지 틀렸는지, 왜 그랬는지 복기하기 위함.

## 원칙 (계속 업데이트할 것)

- 이해하지 못하는 기업에는 투자하지 않는다.
- 가격(Price)과 가치(Value)는 다르다 — 좋은 기업도 비싸게 사면 나쁜 투자다.
- 반도체는 사이클 산업이다. 피크 이익에 낮은 PER로 속지 말고, 사이클 저점의 높은 PER에 겁먹지 말 것.
- 안전마진(Margin of Safety) 없이는 매수하지 않는다.
