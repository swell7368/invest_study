# 반도체 산업 개요

## 1. 밸류체인 구조

```
설계(Fabless/IDM) → 장비/소재 → 파운드리(제조) → 패키징·테스트(OSAT) → 최종 세트업체
```

- **IDM (Integrated Device Manufacturer)**: 설계부터 생산까지 수직계열화. 예: 삼성전자, SK하이닉스, 인텔
- **팹리스 (Fabless)**: 설계만 하고 생산은 외주. 예: 엔비디아, 퀄컴, AMD, 브로드컴
- **파운드리 (Foundry)**: 위탁생산 전문. 예: TSMC, 삼성 파운드리, 인텔 파운드리
- **OSAT**: 패키징·테스트 외주. 예: ASE, Amkor
- **장비**: 노광(ASML), 식각/증착(어플라이드 머티리얼즈, 램리서치, 도쿄일렉트론), 검사(KLA)
- **소재**: 웨이퍼(신에츠, SUMCO), 포토레지스트, 특수가스 등

## 2. 메모리 vs 비메모리(시스템반도체)

| 구분 | 메모리 (DRAM/NAND) | 비메모리 (로직) |
|---|---|---|
| 특징 | 표준화된 제품, 커머디티에 가까움 | 다품종, 설계 차별화 |
| 사이클 | 수요-공급에 따라 가격 변동성 매우 큼 | 상대적으로 완만하나 여전히 순환적 |
| 대표기업 | 삼성전자, SK하이닉스, 마이크론 | TSMC, 엔비디아, 퀄컴, ASML |
| 가치평가 포인트 | 재고/가격(ASP) 사이클, 원가구조(공정 미세화) | 설계 경쟁력, 고객 다변화, 해자 지속성 |

## 3. 반도체 사이클을 만드는 요인
- **수요측**: PC/스마트폰 교체 주기, 서버·AI 투자, 자동차 전장화
- **공급측**: 대형 IDM/파운드리의 Capex 결정 → 2~3년 후 공급 증가로 나타남 (리드타임이 길어 공급 조절이 느림)
- **재고 사이클**: 고객사(세트업체)의 재고 축적/소진이 실제 수요보다 증폭되어 반도체 업체 실적에 반영됨
- **가격(ASP)**: 특히 메모리는 공급과잉 시 원가 이하로도 판매되는 경우가 있어 변동성이 극심

## 4. 최근 구조적 변화 (학습 시 업데이트할 것)
- AI/데이터센터향 고성능 반도체(HBM, GPU) 수요 급증
- 미중 기술패권 경쟁 → 공급망 지역화(디커플링), 보조금 정책(미국 CHIPS Act, 각국 지원책)
- 미세공정 한계 접근에 따른 Capex 부담 증가 (EUV, Gate-All-Around 등)
- 파운드리 과점 심화 (TSMC 선단공정 독점적 지위)

## 5. 분석 시 반드시 확인할 것

- 현재 업황은 사이클의 어느 국면인가 (호황/피크/침체/바닥)?
- 경쟁사 대비 원가구조·기술격차는 어느 정도인가?
- 고객 집중도(특정 고객 의존 리스크)는 어느 정도인가?
